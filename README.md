## Sprint 1

**Sprint goal:** A student can see available menu items, select one or more items with valid quantities, and see a correctly calculated total before submitting an order.

### Definition of Done

An Issue is done only when:

- The behavior matches the requirement and its acceptance criteria.
- Invalid inputs are handled as specified.
- The change has been reviewed by another team member when applicable.
- Relevant tests have passed.
- Any affected SRS documentation is updated.
- The team has checked the acceptance criteria before moving the Issue to **Done**.
